# STUDYMIND-Sistema-de-Gerenciamento-de-Tarefas-ExpoTech

O **StudyMind** é um sistema de gerenciamento de tarefas acadêmicas desenvolvido inteiramente em **Python**, executado no terminal. Seu objetivo é permitir que estudantes organizem suas atividades, definindo informações como matéria, dificuldade, prazo e prioridade para cada tarefa.

O sistema possui autenticação por usuário e senha, garantindo que cada pessoa acesse apenas suas próprias tarefas. Todo o armazenamento de dados é feito em um banco de dados **MySQL**.

### Funcionalidades principais

| Funcionalidade | Descrição |
|---|---|
| Cadastro e Login | Criação de conta e autenticação no sistema |
| Criar Tarefa | Registra uma nova tarefa com múltiplos campos |
| Listar Tarefas | Exibe tarefas pendentes ou todas as tarefas |
| Detalhar Tarefa | Mostra todos os campos de uma tarefa específica |
| Editar Tarefa | Atualiza qualquer campo de uma tarefa existente |
| Excluir Tarefa | Remove uma tarefa com confirmação de segurança |
| Histórico | Registra e exibe tarefas concluídas com tempo gasto |
